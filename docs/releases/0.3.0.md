Producktive 0.3.0 adds automatic software updates.

- Checks for updates daily and installs them when you quit.
- Settings let you disable automatic checks or installation, or check manually.
- Updates verify signed feeds and archives before installation.
- Previously installed agent tools refresh on launch to match the app version.

Requires macOS 13 or later. Supports Apple silicon and Intel.

Install this release manually once to enable automatic updates. Older versions
of Producktive do not contain an updater.
