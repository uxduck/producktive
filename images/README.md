# App icon

`AppIcon.png` is the selected white call-duck variant of DuckType's duck-head
artwork, with a yellow bill and transparent background. Generated with the
built-in image tool from DuckType's `images/icon.png`; its prompt is saved in
`docs/icon-concepts/call-duck-prompt.md`.

`scripts/build-app.sh` generates the standard macOS icon sizes and packages
`AppIcon.icns` into the application. The menu bar remains text-only.
